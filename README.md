# Conta Certa

Crie um app web de Gestão de Contas Correntes em Tailwind e Shadcn com dados em localStorage:

1. CADASTRO DE MODELOS DE RATEIO (CRUD):
- Criar, editar e excluir modelos com: alíquota de imposto (% sobre bruto), deduções fixas sugeridas (R$) e percentual de distribuição (% sobre o saldo líquido restante). Inclua o modelo de exemplo "Aluguel MAM" (14,99% imposto, R$ 4.000 contrato, 80% repasse).
